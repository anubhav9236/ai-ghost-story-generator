    THE LORE BEHIND THE CODE

    Every Ghost Has a Story...

    AI Ghost Story Generator is an open-source creative storytelling application that transforms simple ideas into imaginative ghost stories. Built using Python, Flask, and Google Gemini, it combines interactive web design, CSS animations, and cutting-edge generative AI to create an engaging storytelling experience.

    Whether you are a developer exploring cloud AI orchestration, a horror enthusiast testing spooky prompts, or a creative writer hunting for inspiration, this project proves that immersive gothic experiences can be shared with anyone around the world.

    How Developers Can Extend This Project:

    • ✨ Add new horror sub-genres (Cosmic Horror, Folk Horror, Cyberpunk Ghosts).
    • 🔊 Enhance procedural Web Audio effects with dynamic lightning audio synthesizers.
    • 🎨 Create new CSS animated spectral characters and ambient weather states.
    • 📦 Customize Gemini parameters (temperature, safety settings, tone instructions).
